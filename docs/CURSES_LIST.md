# 👹 Curse Guide (CURSES)

> 🇫🇷 **[Version Française disponible ici](CURSES_LIST_FR.md)**

The bot currently offers **21 different types of curses** that you can cast on server members.

### ⚙️ Command Syntax
- **Cast a random curse**: `!curse @player [duration]`
- **Cast a specific curse (hidden)**: `!curse hidden @player [duration] [TYPE]`
- **Example**: `!curse hidden @victim 15 UWU_MODE`

---

## 💬 Message Alteration (Chat)
These curses modify what the user writes in text channels.

| Type | Name | Effect |
| :--- | :--- | :--- |
| `MESSAGE_SCRAMBLER` | 🔀 **Word Scrambler** | Scrambles the order of words in messages. |
| `MESSAGE_OPPOSER` | 🔄 **Opposer** | Says the opposite of what the user intended to say. |
| `CLOWN_MODE` | 🤡 **Clown Mode** | Adds 🤡 emojis everywhere. |
| `UWU_MODE` | 😺 **UwU Mode** | Transforms text into "UwU" language (>///<). |
| `YODA_MODE` | 🗣️ **Yoda Mode** | Reverses word order like Master Yoda. |
| `CAPS_LOCK` | 📢 **CAPS LOCK** | EVERYTHING IN UPPERCASE WITH EXCLAMATION POINTS!!!! |
| `PIRATE_MODE` | 🏴‍☠️ **Pirate Mode** | Adds pirate expressions (Arr, Matey!). |
| `VOWEL_REMOVER` | 🎯 **Vowel Remover** | Removes all vowels from messages. |
| `REVERSE_TEXT` | 🔁 **Reversed Text** | Writes text backwards. |
| `RANDOM_EMOJI` | 🌈 **Random Emojis** | Replaces some words with strange emojis. |
| `GARBLED` | 🔀 **Garbled Messages** | Garbles commands before they are executed. |
| `POLITE_MODE` | 🤵 **Butler Mode** | Forces the user to be polite (Sir... distinguished greetings). |
| `SHY_MODE` | 😳 **Shy Mode** | Limits messages to 10 characters and truncates them. |
| `EMOJI_ONLY` | 😜 **Emoji Only Mode** | Only emojis are allowed in chat. |
| `QUESTIONER` | ❓ **Questioner** | All messages must end with a question mark. |
| `SELF_DESTRUCT` | 🧨 **Self-Destruct** | Messages delete themselves after 5 to 10 seconds. |
| `PARROT` | 🦜 **The Parrot** | The bot repeats your messages mockingly. |

## 🛠️ Bot Behavior & Commands
These curses change how the bot interacts with the user.

| Type | Name | Effect |
| :--- | :--- | :--- |
| `RANDOM_RESPONSES` | 🎲 **Random Responses** | The bot returns absurd random responses to commands. |
| `IGNORED` | 👻 **Ignored** | The bot completely ignores the user. |
| `BLOCKED` | 🚫 **Blocked** | No commands work for the user. |
| `WORST_LUCK` | 💀 **Worst Luck** | All random results (dice, roulette) are the worst possible. |
| `SLOW_MODE` | 🐌 **Slow Mode** | The bot takes 10 seconds to respond to the user. |
| `REVERSED` | 🔄 **Reversed Commands** | The user's commands turn against them. |
