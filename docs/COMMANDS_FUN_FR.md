## 🎲 Jeux & Hasard

| Commande | Description | Utilisation |
|---------|-------------|-------|
| `!dice [faces]` | Lance un dé (par défaut : 6 faces) | `!dice` ou `!dice 20` |
| `!roll [max]` | Génère un nombre aléatoire (1-100) | `!roll` ou `!roll 1000` |
| `!coin` | Lance une pièce (pile ou face) | `!coin` |
| `!random` | Obtient un nombre aléatoire | `!random` |
| `!roulette` | Joue à la roulette russe | `!roulette` |
| `!roulettehard` | Roulette russe hardcore (exclusion du serveur) | `!roulettehard` |
| `!roulettemute` | Roulette russe avec exclusion vocale | `!roulettemute` |

## 👹 Système de Malédictions (Curses)

Le système de malédictions est l'une des fonctionnalités les plus avancées du bot, vous permettant de perturber les messages ou le comportement d'un utilisateur.

### Commandes Générales
| Commande | Description | Utilisation |
|---------|-------------|-------|
| `!curse @utilisateur [durée]` | Maudit un joueur (type aléatoire) | `!curse @victime 10` |
| `!curse random [durée]` | Maudit un membre vocal au hasard | `!curse random 5` |
| `!curse hidden @utilisateur [durée] [TYPE]` | Malédiction secrète (Admin/Roi) | `!curse hidden @victime 10 UWU_MODE` |
| `!curse types` | Liste tous les types disponibles par message privé | `!curse types` |
| `!curse list` | Affiche les joueurs actuellement maudits | `!curse list` |
| `!curse clear` | Annule toutes les malédictions actives | `!curse clear` |

### 📋 Types de Malédictions Disponibles

Pour voir les détails et effets de chaque type de malédiction, consultez le **[Guide des Malédictions (FR)](CURSES_LIST_FR.md)** ou le **[Curse Guide (EN)](CURSES_LIST.md)**.
